# Claude

Claude es la familia de modelos de Anthropic. Se puede usar como asistente conversacional, desde la API o, en el caso de Claude Code, como agente de desarrollo con acceso al sistema de ficheros, a herramientas y a la ejecución de comandos.

Esa diferencia es la importante: un chat solo produce texto, mientras que un agente actúa. Por eso Claude Code exige configurar con cuidado instrucciones, permisos y automatizaciones.
